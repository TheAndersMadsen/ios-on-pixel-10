  code 0x1 0x0: pc 0x201efa924 lr 0x201ef6298, shared cache slide 0x1f7b4000`, i.e. unslid 0x1e2746924 / 0x1e2742298 =
  CoreBrightness `__TEXT+0x169924` / `+0x165298` (`tools/m1box/dsc_sym.py`, cache 0f1ee332; local symbol, name not in the
  cache). Just before it, backboardd looks for `IOAcceleratorES` 636 times and finds 0 (no GPU service on this kernel).

  (pc 0x1f6906924, slide 0x141c0000 -> 0x1e2746924) 14 times. That run also ended at `deadline 300 s, stage pid1_exec`
