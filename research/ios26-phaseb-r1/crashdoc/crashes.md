- **corebrightness-calibration** (S08): Missing backlight calibration: with hk_bright=140 our AppleARMBacklight has no backlight-calibration-parameters, so CoreBrightness Display init (0x1e2741c1c) takes the fallback and its lookup 0x1e2746810 reads the still-NULL marketing table at 0x1e2746924. Fix: patch 0001-hk-bright-backlight-calibration (calibration + marketing table), or drop hk_bright=140. (`research/ios26-phaseb-r1/corebrightness/FINDINGS.md`)
- **mobilephone-contacts-tcc** (S46): Contacts TCC: +[CNContactStore contactStore] returns nil because tccd does not report kTCCServiceAddressBook authorized; favoritesDataSource.getter force-unwraps it (brk #1). Next: mirror tccd (F2), then seed TCC (F3). (`research/ios26-apps-r1/crashes-r9/FINDINGS.md`)
- **preferences-sandbox-token** (S41): NULL sandbox token: our Sandbox stand-in returns ENOENT for op 5 (extension issue), so containermanagerd hands out NULL tokens and SafariCore WBSSetUpAccessToAppDataContainerWithIdentifier passes NULL to sandbox_extension_consume. Fix F1: op 5 copies out libsandbox's no-op token "invalid". (`research/ios26-apps-r1/crashes-r9/FINDINGS.md`)
- **configd-ionetworkstack** (S48): Main thread waits in SCNetworkInterfaceCopyAll -> _SCDynamicStoreNotifyWait for Plugin:InterfaceNamer; configd writes it only once an IONetworkStack exists (or after its 300 s WaitStackTimeout). Our kernel publishes IONetworkStack only with blazer_usbnet=2 / blazer_wifi_net=2. (`research/ios26-phaseb-r1/configd/FIX.md`)
- **backboardd-nsurl-container** (S24): BaseBoard BSSystemSharedDirectoryForIdentifier got NULL from container_system_path_for_identifier (containermanagerd not ready); phone-side timing, QEMU never reproduces it. hk_container_ready is the fix. (`research/ios26-apps-r1/receipts/l1-r16/LANE1.md`)
- **preferences-launch-watchdog** (S35, S36): runningboard launch watchdog (0x8badf00d): Settings did not finish launching in time. In r10 HKMAIN showed the main thread in _SCDynamicStoreNotifyWait (see configd-ionetworkstack). (`research/ios26-phaseb-r1/configd/FIX.md`)
- **about-preferences-medialibrary** (S58): Settings > About: Preferences aborts (SIGABRT) right after tccd answers its kTCCServiceMediaLibrary request with generic_extension="invalid" (no usable sandbox extension). ABOUT finding, int1. (`ABOUT (int1), coordinator update 2026-11-03`)
- **axui-punctuation-model** (S18, S19, S27, S28, S31): AccessibilityUIServer crash loop: the root build's prune deleted AXSSPunctuationModel.momd, so the CoreData model load throws (abort culprit CoreData 0x185bff6c0) on every respawn. Fix: keep the .momd in the root build. ABOUT finding, int1; matched by process for earlier boots of the same root. (`ABOUT (int1), coordinator update 2026-11-03`)
- **blastdoor-sandbox-check** (S57): MessagesBlastDoorService SIGTRAP: Swift fatalError in Sandbox.swift after sandbox_check, because the SWEET sandbox stub returns 0 for every op. New in int1, launched via callservicesd/CallKit. (`ABOUT (int1), coordinator update 2026-11-03`)
- **blazer-deadline** (S15, S56): Intended end-of-boot timer (blazer_deadline), not a crash: the boot was cut here. A 300 s deadline ends the boot before Home on a slow start. (`research/ios26-phaseb-r1/A7.md`)
